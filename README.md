## 📌 معرفی پروژه

**Shadow Shop Bot** یک ربات فروشگاهی تلگرام مبتنی بر پایتون است که برای مدیریت فروش، کاربران، پرداخت‌ها و امکانات فروشگاهی طراحی شده است.

با توجه به تنظیمات و شخصی‌سازی‌های انجام‌شده، می‌توان از آن برای فروش سرویس‌های دیجیتال، کدهای فعال‌سازی، لایسنس نرم‌افزار، محصولات مجازی و سایر کالاهای دیجیتال استفاده کرد.

مدیریت بسیاری از بخش‌های ربات از طریق پنل مدیریتی تلگرام انجام می‌شود و اطلاعات در پایگاه داده SQLite نگهداری می‌شوند.

## 🧰 پیش‌نیازها

برای نصب ربات به موارد زیر نیاز دارید:

- یک سرور لینوکسی با Ubuntu یا Debian
- Python 3.10 یا نسخه سازگار با وابستگی‌های پروژه
- pip و محیط مجازی پایتون
- توکن ربات تلگرام

- دسترسی SSH به سرور

## 🤖 ساخت ربات تلگرام

۱. در تلگرام به [@BotFather](https://t.me/BotFather) مراجعه کنید.

۲. دستور `/newbot` را ارسال کنید.

۳. نام و نام کاربری ربات را مشخص کنید.

۴. توکن صادرشده را در مکانی امن نگهداری کنید.

برای دریافت شناسه عددی تلگرام خود نیز می‌توانید از ربات‌های معتبر نمایش شناسه کاربری استفاده کنید.

**هشدار امنیتی:** توکن ربات را در GitHub عمومی، گروه‌ها یا اختیار افراد غیرمطمئن قرار ندهید.

## 🐧 آموزش نصب روی لینوکس

### مرحله ۱: به‌روزرسانی سیستم

ابتدا با SSH به سرور متصل شوید و دستورات زیر را اجرا کنید:

```bash
sudo apt update
sudo apt upgrade -y
```

### مرحله ۲: نصب پایتون و ابزارهای موردنیاز

```bash
sudo apt install -y python3 python3-pip python3-venv curl ca-certificates
```

نسخه‌های نصب‌شده را بررسی کنید:

```bash
python3 --version
python3 -m pip --version
```

### مرحله ۳: ساخت پوشه پروژه

```bash
mkdir -p ~/shadow-shop
cd ~/shadow-shop
```

### مرحله ۴: دریافت فایل ربات

```bash
curl -fL "https://github.com/mmpshadow/ShadowShopBot/releases/download/bot/Shadow_Shop.py" -o Shadow_Shop.py
```

بررسی کنید فایل دریافت شده باشد:

```bash
ls -lh Shadow_Shop.py
```

### مرحله ۵: ایجاد محیط مجازی

```bash
python3 -m venv .venv
source .venv/bin/activate
```

سپس pip را به‌روزرسانی کنید:

```bash
python -m pip install --upgrade pip
```

### مرحله ۶: نصب وابستگی‌ها

ربات از کتابخانه `python-telegram-bot` استفاده می‌کند. برای نصب آن اجرا کنید:

```bash
python -m pip install "python-telegram-bot"
```

در صورت نیاز به قابلیت اتصال از طریق پراکسی SOCKS، وابستگی اختیاری زیر را نیز نصب کنید:

```bash
python -m pip install "python-telegram-bot[socks]"
```

> اگر هنگام اجرای ربات خطای مربوط به کتابخانه دیگری مشاهده کردید، نام و نسخه موردنیاز آن را از کد یا پیام خطا بررسی کنید. نصب نسخه‌های ناسازگار کتابخانه‌ها ممکن است باعث اجرا نشدن ربات شود.

### مرحله ۷: تنظیمات اولیه

فایل را با ویرایشگر دلخواه باز کنید:

```bash
nano Shadow_Shop.py
```

در بخش تنظیمات کد، مقادیر مربوط به توکن ربات، شناسه مدیر و سایر تنظیمات ضروری را پیدا کنید و با مقادیر واقعی خود جایگزین کنید.

نام دقیق متغیرها و روش تنظیم آن‌ها را از داخل همان نسخه فایل بررسی کنید؛ از تغییر نام متغیرها بدون بررسی محل استفاده آن‌ها خودداری کنید.

برای ذخیره فایل در `nano`:

- `Ctrl + O` برای ذخیره
- `Enter` برای تأیید
- `Ctrl + X` برای خروج

### مرحله ۸: اجرای ربات

در حالی که محیط مجازی فعال است، اجرا کنید:

```bash
python Shadow_Shop.py
```

سپس صفحه گفت‌وگوی ربات را در تلگرام باز کنید و دستور زیر را بفرستید:

```text
/start
```

اگر ربات اجرا نشد، متن کامل خطای ترمینال را بررسی کنید.

## 🌐 تنظیم پراکسی تلگرام (اختیاری)

در صورتی که سرور برای اتصال مستقیم به تلگرام مشکل دارد، می‌توانید از پراکسی پشتیبانی‌شده استفاده کنید.

در نسخه‌ای که تنظیم `TELEGRAM_PROXY` در آن فعال است، در صورت نیاز مقدار پراکسی را مطابق تنظیمات کد وارد کنید. نمونه زیر برای پراکسی SOCKS5 محلی است:

```bash
export TELEGRAM_PROXY="socks5://127.0.0.1:1080"
python Shadow_Shop.py
```

آدرس بالا صرفاً نمونه است؛ باید با آدرس و پورت پراکسی واقعی شما مطابقت داشته باشد.

اگر پراکسی تنظیم نشده باشد، ربات طبق منطق کد برای اتصال به تلگرام از مسیر مستقیم استفاده می‌کند.

## 🗄️ پایگاه داده و نگهداری اطلاعات

ربات از SQLite برای نگهداری اطلاعات استفاده می‌کند.

- پیش از تغییرات اساسی، از پایگاه داده نسخه پشتیبان تهیه کنید.
- فایل پایگاه داده را حذف نکنید؛ ممکن است اطلاعات کاربران یا تنظیمات در آن ذخیره شده باشد.
- مسیر واقعی پایگاه داده را از تنظیمات `DB_PATH` در کد بررسی کنید.
- نسخه پشتیبان را در مکانی امن نگهداری کنید و دسترسی فایل‌ها را محدود کنید.

## 🧪 عیب‌یابی

### ربات اجرا می‌شود اما پاسخ نمی‌دهد

- توکن ربات را بررسی کنید.
- اتصال سرور به تلگرام را بررسی کنید.
- مطمئن شوید نمونه دیگری از ربات با همان توکن در حال اجرا نیست.
- خطاهای ترمینال را بررسی کنید.

### خطای `ModuleNotFoundError`

مطمئن شوید محیط مجازی فعال است و وابستگی موردنیاز نصب شده است:

```bash
source ~/shadow-shop/.venv/bin/activate
python -m pip list
```

### ربات پس از خروج از SSH متوقف می‌شود

اجرای ساده برنامه در ترمینال ممکن است با پایان نشست SSH متوقف شود. برای اجرای دائمی، استفاده از سرویس `systemd` یا یک مدیر پردازش مناسب توصیه می‌شود. پیش از ساخت سرویس دائمی، مسیر فایل، محیط مجازی و تنظیمات اجرای ربات را بررسی کنید.
